# გაყიდვების CRM-ის ეფექტიანობის ანალიზი

მონაცემთა ანალიზის პროექტი: გამოყენებულია სინთეზური CRM მონაცემები, რომლებიც დავამუშავე (პროფილირება, გაწმენდა, ანალიზი) PostgreSQL-ში, ხოლო ვიზუალიზაცია შევასრულე Power BI-ში.

**მიზანი:** იმის დადგენა, თუ რა განაპირობებს პოტენციური კლიენტების (ლიდების) დათანხმებას და ეფექტიან მუშაობას.

**ხელსაწყოები:** PostgreSQL, SQL, Power BI

## მონაცემები

სინთეზური CRM მონაცემები, რომლებიც შედგება 4 ცხრილისგან (ჩანაწერების რაოდენობა გაწმენდის შემდეგ):

| ცხრილი | ჩანაწერები | აღწერა |
|---|---|---|
| leads | 5,004 | ლიდები: წყარო, პროექტი, სტატუსი, გარიგების ღირებულება, დრო პირველ პასუხამდე  |
| calls | 10,010 | ზარები თითოეული ლიდის მიხედვით (სტატუსი და ხანგრძლივობა) |
| managers | 8 | გაყიდვების მენეჯერები და მათი გუნდები (A და B) |
| tasks | 4,339 | შემდგომი ქმედებების (follow-up) ამოცანები: შესრულების ვადა და დასრულების თარიღი |

პერიოდი: 2026 წლის ივლისი – სექტემბერი.

## ძირითადი მიგნებები

1. **საუბრის ხანგრძლივობა ყველაზე მნიშვნელოვანი მაჩვენებელია.** წარმატების მაჩვენებელი იზრდება 1,4%-დან (5 წუთზე ნაკლები საუბრის შემთხვევაში) 55,6%-მდე (15 წუთზე მეტი საუბრის შემთხვევაში). იმ ლიდებთან, რომლებთან საუბარიც 15 წუთზე მეტხანს გრძელდება, წარმატების ალბათობა დაახლოებით 40-ჯერ უფრო მაღალია.
2. **რეკომენდაციები (რეფერალები) უფრო ეფექტიანია, ვიდრე რეკლამა.** რეკომენდაციების შემთხვევაში წარმატების მაჩვენებელი 22,4%-ია, ხოლო რეკლამის შემთხვევაში — მხოლოდ 5,0%, მიუხედავად იმისა, რომ ლიდების რაოდენობა დაახლოებით თანაბარია.
3. **„პროექტი გამა“ (Project Gamma) ყველაზე მეტს გამოიმუშავებს.** მიღებულმა შემოსავალმა 44,5 მილიონი შეადგინა, რაც თითქმის 3-ჯერ აღემატება „პროექტი ალფას“ (Project Alpha) შედეგს (15,5 მილიონი). ამას გარიგების უფრო მაღალი საშუალო ღირებულება (181 ათასი „გამას“ შემთხვევაში, 75 ათასის წინააღმდეგ — „ალფას“ შემთხვევაში) განაპირობებს.
4. **დავალებების მესამედი არასდროს სრულდება** (თითოეული მენეჯერის შემთხვევაში ეს მაჩვენებელი 32-35%-ია); ეს გუნდური პრობლემაა და არა მხოლოდ კონკრეტული მენეჯერის.
5. **პასუხის გაცემის სიჩქარესა და მენეჯერის კვალიფიკაციას მხოლოდ მცირე გავლენა აქვს.** წარმატების მაჩვენებელი პასუხის გაცემის სხვადასხვა დროის შემთხვევაში (13-15%), თითქმის თანაბარია, ასეეე მენეჯერებს შორის განსხვავებაც მცირეა (11-16%).

შენიშვნა: ზარებისა და საუბრის ხანგრძლივობის მონაცემები მიუთითებს ძლიერ კავშირზე, თუმცა ეს არ ნიშნავს მიზეზ-შედეგობრივ კავშირს. აღნიშნული კორელაცია შეიძლება იმითაც აიხსნას, რომ იმ ლიდებს, რომლებიც უკვე მზად არიან შესასყიდად, უფრო ხშირად უკავშირდებიან.
